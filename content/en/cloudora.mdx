Cloudora was built from scratch using Laravel 11, focusing on delivering a modern, fast, and secure cloud storage experience. The application features a clean and intuitive interface that allows users to efficiently manage various types of files.

**Key Features:**
- File upload and management
- Fast file search functionality
- File categorization (Images, Documents, Videos, and more)
- Starred files for quick access
- Recycle Bin for recovering deleted files
- Dashboard with storage usage and file statistics
- Responsive modern interface with Dark Mode support
